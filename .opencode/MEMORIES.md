## Architecture

- `sim/` — Haskell package `rel-sim`: `Sim.Engine` (order book: `Side`/`Order`/`Book`/`Trade`, volumes positive by construction via `mkVol`), `Sim.Gen` (seeded splitmix generator; `refPrice own other` = opposite-side-best-first — callers pass own side first), `Sim.TickGen` (tick export, duplicated roll helpers — do NOT share with Sim.Gen, exporting them costs ~40% runSim perf), `Sim.Cli`/`Sim.Csv` (CSV: open,high,low,close,vol — vol = sum of trade volumes), `SimFFI` (foreign-library, C ABI `sim_generate`). QuickCheck suite runs in the nix build (buildPhase).
- tick modes: `--mode tick-trades|tick-steps` (+ `--book-depth N`, default 50 = old GDScript `ob_depth`) writes `<out>.ticks.csv` sidecar next to the candles csv: `c,price,vol` + book-depth `(bp,bv,ap,av)` quads padded with `0.00000,0`; `vol=0` rows are book-only (marker = last row of every candle, exact end-of-candle book). UI: sim panel mode dropdown; chart aggregates ticks to candles and plays the per-candle book snapshot at the replay head (`Series.books`, `OrderBookWidget.set_book`); plain csvs keep the synthetic ladder.
- price ref (2026-10-13, updated): the `opposite` price-ref mode is REMOVED — `RefMode`/`spRefMode`/`--price-ref`/the UI "price ref" dropdown are gone; mid anchoring is the only behavior (`oppositeRef` survives as the one-sided fallback inside the mid chain). Spike history: leftover volume rested up to `tick-range` beyond the OPPOSITE touch, bid/ask stacks did independent random walks, spread never closed (processOrders only matches `bp >= ap`). Mid alone kills spikes (max close-to-close move 0.0035 @20k×500 seed 7, same as with clamp). COST: mid reads both book sides per order — new 100k×1k baseline ≈ 16.7s (old opposite baseline was 11.7s); that +40% is intrinsic to mid, don't chase it in the engine without a bigger refactor. `--clamp-rest on|off` stays (UI checkbox).

Math in Haskell `Sim.Fft.fftApprox`: unboxed iterative FFT (top-k padded bins SNAPPED to exact window DFT bins q/n + dedup — snapped columns are exactly orthogonal so the solve provably cannot explode; non-snapped frequencies explode on real data at waves≥40, do NOT revert) + HARD LOW-PASS q ≤ n/8 (shorter-period bins fit per-candle noise — on real candles the spectrum is noise-flat, so without the low-pass top-k picks arbitrary period-2..10 bins and the forecast jumps around then flatlines; with it max jump ≈ 0.3x median candle move) → ridge-LS via closed-form Dirichlet-kernel Gram + Jacobi eigendecomp on STUArray (near-null truncation kept as belt-and-braces) → synthesis by rotation recurrence (unboxed ST). - FFT bin refinement (2026-10-15, on top of the sinus generator work): the snapped-only fit was exact only when the window held an integer number of cycles; fractional cycles put the true frequency up to half a bin off the q/n grid and the fit drifted out of phase toward the window edges (edge err up to the full amplitude, forecast worse). Fix in `Sim.Fft`: `topPeaks` keeps the padded peak position next to the snapped bin and non-maximum-suppresses picks within ±ceil(m/n) padded bins (mainlobe halfwidth — without it one strong wave's straddle starves weaker harmonics of the top-k slots, sum-of-waves fit rms was 35 ticks on an exact 5-cycle window); `refinePeaks` re-estimates the top-2 bins by ternary max of the single-component LS energy within 1 window bin of the PADDED peak (the snap round(j·n/m) can sit a full bin off). CRITICAL: the objective must be the intercept-adjusted explained energy bᵀG⁻¹b with CENTERED Gram — raw c²+s² peaks ~0.06-0.1 bin off at low frequencies (columns not orthogonal/equal-norm off-bin), and demeaning alone is NOT an intercept: the window mean is outside the cos/sin span, the no-intercept fit compromises toward the leftover DC (μ≈17 ticks → 0.03-bin shift, 20-tick floor). The solve is now intercept-extended (`gramWI`/`corrWI`/`solveGBI`, constant column first, closed-form weighted sums). Refined freqs replace snapped only when in-window SSE wins by a 10% MARGIN — without the margin a near-bin refinement absorbs second-harmonic leakage and breaks the waves=1 exact-bin projection contract (prop_fft_waves_limit). Refinement runs only for k ≤ 16 waves (auto default ≤ 8); a refined value colliding with another bin (closer than half a bin) falls back to its snapped anchor. Gotcha cost a cycle: refactoring gramW's cc/ss into top-level wCos/wSin dropped the edge-ramp term at c≈0 (moved inside the Dirichlet guard) — fft_gram_matches_bruteforce caught it (diag off by 2·a·rampMass). Measured on quantized sinus scans (n 80-199, p 9-49): worst fit/fc err 0.45 ticks (pure, quantization floor) and 11.6/23 ticks (two-wave auto, small-window CRLB-ish); pre-fix 126+/164. fftBest 30k ≈ 3.5ms, fftApprox ~1.3ms/call cached in UI. - MKV indicator (2026-10-17, reworked same day: window-sum classification is the ONLY behavior): "add MKV" in the RMB menu. `Sim.Markov` (sim/src/Sim/Markov.hs): per-bar 15-double record `[bsbpBull/Sw/Bear, t00..t22 row-major, surprise, rolling surprise, lambda]`. **Classification = window sum**: state of bar i from the SUM of the last `period` close-to-close returns (%) ending at it, PARTIAL while the window fills (bar 3 sums returns [1..3]; every bar classifiable from bar 1, first transition at bar 2, BSBP NaN until i≥period). ≥+th Bull, <−th Bear. **`mpWeighted` (UI "w")**: linear recency ramp, weight `(j−lo+1)·2/(cnt+1)` — scale-preserving (equal returns give the same sum as plain, threshold stays comparable); O(1)/bar in GDScript via two running sums `(Σj·rⱼ −(lo−1)·Σrⱼ)·2/(cnt+1)`, in Haskell via a second prefix sum. Prefix-sum impl; `statesOf` exports the states. **THE FFI TAKES PRE-CLASSIFIED STATES (int32), NOT closes** (`sim_markov(states, count, win, surpwin, λ…)`): the widget computes states once for the WHOLE loaded slice (`_mkv_states_ensure`, IndCache.states/sums/states_key) so classification is EXACT for any subslice — passing closes let the FFI truncate window sums at the cache-slice edge (first `period` bars of every fill got wrong states; symptom: bar 500 all-Sideways inside a real trend). IndCache also caches `sums` (signed window sum per bar) + `th_resolved` for the band. Matrix chain still restarts at the slice start (uniform prior, cache key carries win_off) — accepted path-dependence. ## Nix gotchas (all cost a build cycle)

- **Nix builds from the git tree.** Untracked/intent-to-add files are invisible → `can't find source for ...`. Always `git add` before `nix build` / `nix flake check`. `flake.nix` itself must be tracked to evaluate.
- `nix build .#sim-extension` retargets the `./result` symlink away from redot — re-run `nix build .#redot` (cached) or use the store path directly.
- Redot editor scans **every `.gdextension` under `res://`** — never keep template `.gdextension` files in source dirs (it creates `extension_list.cfg` entries). Template lives in `nix/gdextension.nix`.
- Haskell foreign-library on nixpkgs: needs `-fPIC` on the **library stanza**, plus `splitmix` override with `--ghc-options=-fPIC` (`nix/sim.nix`). `options: standalone` does NOT work (nix GHC's static RTS is non-PIC) — link RTS dynamically and fix rpaths with `autoPatchelfHook` in the consumer.
- GHC RTS does not self-init when dlopen'ed — `hs_init` via `__attribute__((constructor))` in the shim, else `newBoundTask: RTS is not initialised`.
- GDExtension is `reloadable = false` ON PURPOSE (nix/gdextension.nix): the shim runs `hs_exit` on unload and the GHC RTS cannot be reinitialized after `hs_exit`. Redot's editor auto-reloads a changed `.so` on focus → wedge: generation completes (CSV on disk) but the worker thread never returns to Godot → panel polls `is_alive()` forever, UI looks frozen, Cancel stays disabled. After `link-sim-extension` a FULL editor restart is required; a days-old editor session silently keeps the stale lib (which is also how "code 1 after relink" happens: old scalar parser still in memory). Verified: fresh-process async generate (thread + progress polling) works headlessly every time.
- nix ''-string pitfall (cost a build cycle): comment lines inserted into the indented heredoc in nix/gdextension.nix must KEEP the block's 4-space indent — unindented lines shift the common-indent dedent, the `EOF` terminator drifts, the heredoc eats the rest of the phase, and the build SUCCEEDS with an empty `bin/`.
- Cabal rejects module + dir name clash (`Sim.Types` file + `Sim.Types/` dir) — internal module is flat `Sim.Internal`.
- `cp` from nix store into project: `rm -f` target first + `chmod u+w` (store perms are read-only).

- `:=` inference fails on Variant chains (Dictionary values, untyped node vars) — annotate the var type explicitly.
- Inner classes: access via `const PlotDataScript := preload(...)` then `PlotDataScript.Series.new()`, not via node instance.
